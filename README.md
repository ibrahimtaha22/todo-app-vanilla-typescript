# Todo App

A responsive todo app built as a JavaScript learning project, based on the [Frontend Mentor Todo App challenge](https://www.frontendmentor.io/challenges/todo-app-Su1_KokOW).

## Features

- Add, complete, and delete tasks
- Filter tasks by all, active, or completed
- Clear completed tasks
- Switch between light and dark themes
- Drag and drop tasks to change their order
- Save tasks and theme settings in local storage
- Responsive layout for mobile and desktop

## Built With

- HTML
- TypeScript
- Tailwind CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```

To create a production build, run:

```bash
npm run build
```

## What I Learned

- How to build a responsive layout
- How to update the page with TypeScript and DOM events
- How to save and load data with local storage
- How to filter, complete, and reorder tasks
- How to add a light and dark theme
